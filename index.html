Python тіліндегі рекурсия

Рекурсия — функцияның өзін-өзі шақыруы. Үлкен есепті сол есептің кішірек нұсқасына бөліп, қадам сайын шешуге мүмкіндік беретін қуатты тәсіл.

Оқуды бастау
Қарапайым мысал: матрешка қуыршағын ашсаңыз, ішінен кішірек матрешка шығады. Ең кішісіне жеткенше осылай жалғаса береді. Рекурсия да дәл солай жұмыс істейді.

Теория

Рекурсия дегеніміз не?

Рекурсия — функция өз денесінің ішінде өзін шақыратын бағдарламалау тәсілі. Әр шақырған сайын есеп кішірейеді, соңында ең қарапайым жағдайға жетеді де, жауап кері қарай жинала бастайды. Рекурсия әсіресе есепті бір-біріне ұқсас кішкентай бөліктерге бөлуге болатын кезде ыңғайлы.

Рекурсивті функция қалай жұмыс істейді?

Функция шақырылғанда Python оны «шақырулар стегіне» (call stack) қояды. Функция өзін қайта шақырса, жаңа шақыру стектің үстіне қосылады. Тоқтау шарты орындалғанда ең соңғы шақыру нәтиже қайтарады, содан кейін стек бірте-бірте босап, әр шақыру өз жауабын алады.

Base Case (тоқтау шарты) дегеніміз не?

Base case — рекурсияны тоқтататын ең қарапайым жағдай. Мұнда функция өзін қайта шақырмай, дайын жауапты тікелей қайтарады. Мысалы, факториалда n == 0 болса, жауап 1. Тоқтау шарты болмаса, функция шексіз шақырыла береді.

Recursive Call (рекурсивті шақыру) дегеніміз не?

Recursive call — функцияның өз денесінде өзін қайта шақыруы. Бұл шақыруда аргумент әрдайым тоқтау шартына жақындайтындай өзгереді, мысалы n - 1. Егер аргумент тоқтау шартына жақындамаса, рекурсия ешқашан аяқталмайды.

def funksiya(n):
    # 1) Base case: тоқтау шарты
    if n == 0:
        return 1
    # 2) Recursive call: есепті кішірейтіп, өзін шақыру
    return funksiya(n - 1)

Python мысалдары

1. Факториалды есептеу

def factorial(n):
    # Base case: 0! = 1 және 1! = 1
    if n == 0 or n == 1:
        return 1
    # Recursive call: n! = n * (n - 1)!
    return n * factorial(n - 1)

print(factorial(5))
120

Санның факториалы — 1-ден сол санға дейінгі барлық сандардың көбейтіндісі: 5! = 5 · 4 · 3 · 2 · 1 = 120. Функция factorial(5) есебін 5 * factorial(4) деп бөледі, ол әрі қарай 4 * factorial(3) болады. Сөйтіп factorial(1)-ге жеткенде тоқтап, жауап кері қарай көбейтіліп жиналады.

2. Фибоначчи сандары

def fibonacci(n):
    # Base case: алғашқы екі сан
    if n == 0:
        return 0
    if n == 1:
        return 1
    # Recursive call: алдыңғы екі санның қосындысы
    return fibonacci(n - 1) + fibonacci(n - 2)

for i in range(8):
    print(fibonacci(i), end=" ")
0 1 1 2 3 5 8 13

Фибоначчи тізбегінде әр сан алдыңғы екі санның қосындысына тең: 0, 1, 1, 2, 3, 5, 8, 13... Бұл жерде екі тоқтау шарты бар (n == 0 және n == 1) және функция өзін екі рет шақырады. Үлкен n үшін бұл тәсіл баяу жұмыс істейді, өйткені бір мәндер қайта-қайта есептеледі.

3. Кері санау

def countdown(n):
    # Base case: 0-ге жеткенде тоқтаймыз
    if n == 0:
        print("Старт!")
        return
    print(n)
    # Recursive call: санды 1-ге азайтамыз
    countdown(n - 1)

countdown(5)
5 4 3 2 1 Старт!

Функция алдымен ағымдағы санды басып шығарады, содан кейін өзін n - 1 мәнімен шақырады. Сан 0 болғанда «Старт!» жазылып, рекурсия тоқтайды. Әр қадамда n кішірейіп, тоқтау шартына жақындай түседі.

Көрнекі көрсету

Матрешка қуыршағын елестетіңіз: қорапты ашсаңыз, ішінен кішірек қорап шығады. Ең кішісіне жеткенше осылай жалғаса береді. Төмендегі түймені басып, қораптарды бір-бірлеп ашып көріңіз.

Қорапты ашу — рекурсивті шақыру. Ең кіші бос қорап — тоқтау шарты (base case).
